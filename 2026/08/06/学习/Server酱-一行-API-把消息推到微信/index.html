Server酱：一行 API 把消息推到微信

为什么需要它？

写定时任务、跑爬虫、监控服务器……脚本跑完后，常常只能打开日志才知道结果。更烦的是，脚本半夜跑完失败，第二天早上才发现。如果能让它跑完直接把结果”喊”到手机上，就省事多了。

微信是最常用、最不容易漏看的消息入口。Server酱（ServerChan）做的就是这件事：给一个 HTTP 接口发请求，就能把消息推到你的微信，全程只需要一个「SendKey」。

什么是 Server酱

Server酱是一个极简的消息推送服务：服务器、脚本、设备通过一个 HTTP 请求调用它的接口，它再把内容以通知的形式发到你的微信。对使用者来说，不需要申请微信公众号、不需要理解微信开放平台那一堆 token，登录绑定后填一个 SendKey 就能用。

目前 Server酱有两个产品线：

  • Server酱·Turbo 版（sct.ftqq.com）：走微信推送，也是大家通常说的”Server酱”。注册后免费额度为 5 条/天。
  • Server酱³（sc3.ft07.com）：较新的产品线，走自家的 App 客户端推送，支持 AI 摘要、翻译、多设备，接口参数与 Turbo 版基本兼容，但 SendKey 不通用，目前测试期免费。

旧版的 sc.ftqq.com 已经分期下线，新用户直接使用 Turbo 版即可。

背后其实很简单：Server酱 替你维护了微信公众号这一整套东西，你登录绑定的微信收到的是「服务通知」类消息。SendKey 相当于你的账号钥匙，接口由官方托管，所以你不用申请公众号、不用维护服务器，一个请求就完成了从你的设备到微信的整段路程。

快速上手：三步跑通

  1. 打开 sct.ftqq.com，微信扫码登录。
  2. 进入 SendKey 页面，生成并复制你的 SendKey。
  3. 往 https://sctapi.ftqq.com/<SendKey>.send 发一个 POST 请求，传 title（标题，必填）和 desp（正文，支持 Markdown）。返回 code: 0 就表示推送成功。

如果你要把它嵌进自己开发的应用或网页，官方还提供了 AppKey（应用专用 SendKey）：它只能用来调推送接口，不能登录账号，权限更小，适合暴露给应用而不是真人。

免费额度与收费

Turbo 版免费额度为每天 5 条，超出后需要订阅会员，具体价格以官网为准。5 条/天对”脚本跑完通知一声”的场景通常够用；如果你每天有几十条告警，要么升级会员，要么考虑下面提到的替代方案。

Server酱³ 目前测试期免费，正式版收费会与 Turbo 版一致；它自带的 AI 摘要等功能单独按点数计费，普通推送用不到，这里不展开。

常见坑

  • **SendKey 就是你的”钥匙”**：拿到 SendKey 的人可以往你的微信发消息，所以绝不能提交到公开仓库。本项目里 SendKey 放在 .agents/skills/bank-promo/secrets/notify.json，并在 .gitignore 中排除，仓库里只保留 notify.example.json 模板。
  • desp 是 Markdown：正文里换行要用两个换行符（\n\n），否则渲染出来挤在一起；不支持 HTML 标签。
  • 别刷屏：5 条免费额度加上推送频率限制，都在提醒你只在真正需要时推送。脚本里可以加去重或节流，避免同一内容反复推送。

替代方案速查

方案 推送渠道 免费额度 特点
Server酱 微信公众号 5 条/天 国内，接入最简单
PushPlus 微信公众号 有免费额度（限次） 国内备选
Bark iOS 系统通知 免费 仅 iPhone，可自建服务端
Telegram Bot Telegram 免费 需要能访问 Telegram
ntfy Android / iOS / Web 免费 开源，可完全自建
企业微信机器人 企业微信群 免费 适合发到团队群

怎么选？个人脚本、轻量监控，Server酱 或 Bark 最简单；通知要发给整个团队，用企业微信机器人；如果消息敏感、想完全掌控数据，就自建 ntfy。替换成本都很低，因为它们的核心用法都是”填一个 token，发一个 HTTP 请求”。

小结

Server酱把”服务器 → 微信”这条通知链路压缩成了一个 HTTP 请求，注册、接入都足够简单，适合绝大多数个人脚本和轻量监控场景。先用它跑通自己的需求，等量大了再根据预算和渠道偏好选择升级或换方案。

那，要不要给你的定时任务也加一句推送？
